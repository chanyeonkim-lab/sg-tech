**인천환경공단 승기사업소 송도지소 재이용시설**의 **「송도재이용시설 1단계 배수펌프 전기공사」**에 사용하는 배수펌프 제어반 제작 사례입니다. SG기전은 분전반 제작과 함께 도면 작성 및 승인도서 문서 준비를 진행했습니다.

이 글은 설계·구매·시설 담당자를 위해 구성과 문서 준비 범위를 설명합니다. 간단한 제작 사례와 상담 안내는 [짧은 사례 소개](/blog/2026-09-24-songdo-sewage-pump-sus-panel)에서 볼 수 있습니다.

사진은 **공장 제작 단계**를 촬영한 것으로 현장 설치·시운전 완료 사진이 아닙니다. 외함과 전면판에 붙어 있는 필름은 제작 중 표면을 보호하기 위한 것입니다.

## 1. SUS304 함체와 전면 조작부

외형도 기준 함체는 **폭 600 × 높이 800 × 깊이 350 mm, SUS304**입니다. 스테인리스 함체는 습기와 부식 환경을 고려한 선택입니다. 실제 설치 조건에 맞춰 도어 밀폐, 케이블 인입과 지지 구조까지 함께 검토합니다.

전면에는 펌프 A·B를 구분해 조작할 수 있도록 **수동·자동 선택 스위치와 ON·OFF·FAULT 표시·조작부**, 디지털 모터보호계전기 지시창을 구성했습니다. 외부 도어의 투시창을 통해 내부 조작부를 볼 수 있는 형태입니다.

![수동·자동 선택 스위치와 ON·OFF·FAULT 표시부가 배치된 배수펌프 제어반 전면](/images/songdo-pump-panel-controls.webp)

표시부와 조작부를 계통별로 나란히 배치해 운전자가 어느 펌프를 확인하고 조작하는지 구분하기 쉽도록 했습니다.

## 2. 펌프 전력 계통과 모터보호

단선결선도는 **배수펌프 A를 상용, B를 예비**로 구분합니다. 펌프별로 차단기, 전자접촉기와 디지털 모터보호계전기 등을 구성하며, 제작 사진에서도 두 모터 계통의 기기와 배선을 확인할 수 있습니다.

| 구성 | 역할 및 검토 항목 |
| --- | --- |
| MCCB | 메인·분기 전력 계통을 구분하고, 부하 및 보호 조건에 맞는 사양 검토 |
| 전자접촉기(MC) | 제어 신호에 따른 펌프 전원 개폐 |
| 디지털 모터보호계전기(DMP) | 모터 운전 상태 표시와 보호 기능 구성 |
| ZCT | 누전 검출을 위한 구성과 보호계전기 조합 확인 |
| 콘덴서 | 모터 계통에 반영된 부품으로 용량·결선 조건 확인 |
| 퓨즈·단자대 | 제어 전원 보호와 외부 배선 접속 구분 |

자료에는 LS ELECTRIC 계열 차단기·전자접촉기·모터보호계전기가 기재되어 있습니다. 기기의 최종 정격과 보호 설정은 승인된 사양에 맞춰 확인합니다.

상용·예비 펌프의 운전 순서와 전환 조건은 현장 요구에 맞는 펌프 제어 시퀀스와 승인된 회로를 기준으로 정리합니다. 상용·예비 구성이라는 이유만으로 자동 교대 운전 기능을 뜻하는 것은 아닙니다.

## 3. 수위제어와 외부 접속

내부배치도에는 **배수 PIT용 플로트리스 스위치 2회로와 4극 전극봉 조건**이 기재되어 있습니다. 제작 사진에서도 두 수위제어 기기가 확인됩니다. 수위 신호를 받아 펌프를 제어하는 구성으로, 수동 조작과 자동 운전의 관계도 문서에 명확하게 정리합니다.

수위제어 사양서와 시퀀스도에서는 다음 항목을 서로 맞춰 검토합니다.

- 전극봉 구성과 현장 배선 접속
- 펌프 기동·정지에 사용하는 수위 조건
- 상용·예비 펌프의 운전 조건과 수동·자동 선택 관계
- 고장 표시 및 필요한 경보·외부 신호 범위

![배수펌프 제어반 도어 뒷면의 배선 덕트와 선번이 표시된 조작부 배선](/images/songdo-pump-panel-door-wiring.webp)

도어 조작부 배선은 덕트를 따라 정리하고 선번을 표시했습니다. 단자대 결선도와 선번을 맞추면 현장 결선과 유지보수 시 회로를 추적하기 쉬워집니다.

## 4. 점검 조명과 결로 관리

펌프 제어 기능 외에도 내부 점검을 돕는 조명과 결로 관리용 히터·온도조절기를 반영했습니다.

![배수펌프 분전반 상부에 설치된 내부 조명과 도어 리미트 스위치](/images/songdo-pump-panel-light.webp)

내부 조명은 어두운 설치 공간에서 기기와 배선 확인을 돕습니다. 조명의 점등 방식은 도어 리미트 스위치와 해당 회로 구성에 맞춰 확인합니다.

![배수펌프 분전반 측면의 스페이스 히터와 온도조절기 및 모터보호 기기](/images/songdo-pump-panel-heater.webp)

스페이스 히터와 온도조절기는 함체 내부의 결로 관리에 사용하는 보조설비입니다. 설치 환경과 밀폐 상태, 온도 설정 조건을 함께 검토합니다.

## 5. 승인도서 12종 준비 범위

이번 배수펌프 전기공사 관련 **승인도서 문서 준비 항목은 아래 12종**입니다. 외형·기기 배치·전력 계통·제어 동작·외부 접속과 자재 사양이 서로 맞도록 정리하는 작업입니다.

| 문서 | 정리하는 내용 |
| --- | --- |
| 1. 제작승인서 | 제작 대상과 제출 사양, 검토·승인 요청 내용 |
| 2. 외형도 | 함체 치수, 도어와 조작부, 인입·지지 구조 |
| 3. 내부배치도 | 기기·덕트·단자대 배치와 점검 공간 |
| 4. 단선결선도 | 인입 전원, 메인·분기와 부하 계통 |
| 5. 주·제어회로도 | 주전력 회로와 운전·정지·보호 제어 구성 |
| 6. 단자대 결선도 | 외부 케이블 접속 단자와 선번 구분 |
| 7. 펌프 제어 시퀀스도 | 수위·운전모드·보호 조건에 따른 동작 순서 |
| 8. 부하계산서 | 부하 조건과 전원·기기 용량 검토 근거 |
| 9. 주요 자재 사양서 | 적용 기기의 모델·정격·기능 정리 |
| 10. 수위제어 사양서 | 전극봉·검출 방식과 운전 수위 조건 |
| 11. 제품 카탈로그 | 사양 검토를 위한 제조사 자료 |
| 12. 시험검사계획서 | 검사 항목·방법과 확인·기록 계획 |

문서 준비 후에는 발주처 검토와 승인 절차에 맞춰 내용을 확인하고, 제작·검사 단계에서 해당 사양과 대조합니다.

## 6. 설계·승인도서부터 제작까지 상담하세요

공개 사례에는 제작 사진과 기능·문서 종류를 소개합니다. 현장별 회로도, 상세 결선과 승인도서 원본은 **발주처 공유 조건과 공개 가능 범위를 확인한 뒤** 개별 상담에서 검토합니다.

상담 시에는 펌프 사양·수량, 전원 조건, 설치 환경, 수위 검출 방식, 운전 요구와 제출 서류 목록을 보내주세요. 승인도서 준비 범위부터 제작·납품까지 함께 검토하겠습니다. 현장 전기공사와 설치는 해당 공사를 담당하는 전기공사 업체가 수행합니다.
