에스지기전은 인천환경공단 승기사업소 송도지소 재이용시설의 「송도재이용시설 1단계 배수펌프 전기공사」에 사용하는 배수펌프 제어반을 제작했습니다. 펌프 전력 계통과 수위제어, 모터보호 기능을 구성하고, 도면 작성과 승인도서 준비도 함께 진행했습니다.

이번 제어반에 사용한 부품과 각 기능, 승인도서 준비 내용을 소개합니다. 주요 기능을 간단히 보시려면 [공공기관 제작 사례 소개: 배수펌프 제어 분전반 제작 사례](/blog/2026-09-24-songdo-sewage-pump-sus-panel)를 참고하세요.

아래 사진은 공장에서 제작한 제어반의 모습입니다. 외함과 전면판에는 제작 중 스테인리스 표면을 보호하기 위한 필름이 붙어 있습니다.

## 1. SUS304 함체와 전면 조작부

함체는 폭 600 × 높이 800 × 깊이 350 mm 규격의 SUS304 스테인리스로 제작했습니다. 재이용시설의 습기와 부식 환경을 고려해 스테인리스를 사용하고, 도어와 케이블 인입부, 지지 구조를 현장 조건에 맞춰 구성했습니다.

전면에는 펌프 A·B를 각각 조작할 수 있도록 수동·자동 선택 스위치와 ON·OFF·FAULT 표시·조작부, 디지털 모터보호계전기 지시창을 배치했습니다. 외부 도어에 투시창을 적용해 도어를 닫은 상태에서도 운전 표시를 볼 수 있도록 했습니다.

![수동·자동 선택 스위치와 ON·OFF·FAULT 표시부가 배치된 배수펌프 제어반 전면](/images/songdo-pump-panel-controls.webp)

표시부와 조작부를 계통별로 나란히 배치해 운전자가 어느 펌프를 확인하고 조작하는지 구분하기 쉽도록 했습니다.

## 2. 펌프 전력 계통과 모터보호

공공기관에 사용하는 제어반인 만큼 자재 사양도 중요하게 검토했습니다. 이번 제작에는 LS ELECTRIC 차단기·전자접촉기·디지털 모터보호계전기를 사용했습니다.

배수펌프 A는 상용, B는 예비 계통으로 구성했습니다. 펌프별로 차단기와 전자접촉기, 모터보호 기기를 배치해 각 펌프의 전원 개폐와 운전 상태를 관리하도록 했습니다.

| 구성 | 역할 |
| --- | --- |
| 차단기(MCCB) | 메인·분기 회로의 전원을 개폐하고 과전류·단락으로부터 회로 보호 |
| 전자접촉기(MC) | 제어 신호에 따라 펌프 전원을 연결하거나 차단 |
| 디지털 모터보호계전기(DMP) | 모터 운전 전류를 표시하고 이상을 감지해 모터 보호 |
| ZCT | 누전으로 발생하는 전류 불균형을 검출해 보호 기기에 신호 전달 |
| 퓨즈 | 제어 회로의 과전류 보호 |
| 단자대 | 외부 전원·펌프·수위 감지 배선을 정해진 단자에 접속 |

누전 경보 기능도 구성했습니다. 누전 경보 조건에 해당하는 이상이 감지되면 경보가 울려 담당자가 전기 이상을 확인할 수 있습니다. 펌프별 운전 조건과 경보 동작은 주·제어회로도와 펌프 제어 시퀀스도에 정리했습니다.

## 3. 수위제어와 외부 접속

배수 PIT용 플로트리스 스위치 2회로와 4극 전극봉을 사용했습니다. 전극봉은 물이 닿는 위치에 따라 수위를 감지하는 역할을 합니다. 서로 다른 높이에 설치한 전극봉을 통해 물 높이를 구분합니다.

플로트리스 스위치 컨트롤 팩(Floatless Switch Control Pack)은 전극봉에서 들어오는 신호를 받아 펌프 제어에 사용하는 수위제어 기기입니다. 물 위에 뜨는 부표 대신 전극봉으로 수위를 감지하며, 감지한 신호를 펌프 운전과 알람에 사용합니다. 물이 설정한 경보 수위에 도달하면 알람으로 알려 배수 상태를 확인할 수 있도록 했습니다.

수동·자동 선택 스위치는 운전자가 직접 조작하는 방식과 수위 신호에 따라 운전하는 방식을 선택하는 데 사용합니다. 전극봉 접속과 펌프 동작 조건은 수위제어 사양서·시퀀스도·단자대 결선도에 맞춰 정리했습니다.

수위제어 관련 문서에는 다음 내용을 담았습니다.

- 전극봉 구성과 현장 배선 접속
- 펌프 기동·정지에 사용하는 수위 조건
- 상용·예비 펌프의 운전 조건과 수동·자동 선택 관계
- 고장 표시 및 필요한 경보·외부 신호 범위

![배수펌프 제어반 도어 뒷면의 배선 덕트와 선번이 표시된 조작부 배선](/images/songdo-pump-panel-door-wiring.webp)

도어 조작부 배선은 덕트를 따라 정리하고 선번을 표시했습니다. 단자대 결선도와 선번을 맞추면 현장 결선과 유지보수 시 회로를 추적하기 쉬워집니다.

## 4. 점검 조명과 결로 관리

펌프 제어 기능 외에도 내부 점검을 돕는 조명과 결로 관리용 히터·온도조절기를 반영했습니다.

![배수펌프 분전반 상부에 설치된 내부 조명과 도어 리미트 스위치](/images/songdo-pump-panel-light.webp)

내부 조명은 어두운 설치 공간에서 기기와 배선을 보기 쉽게 돕습니다. 도어 리미트 스위치는 도어의 열림·닫힘 상태를 감지하는 기기로, 조명 제어에 사용했습니다.

![배수펌프 분전반 측면의 스페이스 히터와 온도조절기 및 모터보호 기기](/images/songdo-pump-panel-heater.webp)

스페이스 히터는 함체 내부를 가열해 결로를 줄이는 데 사용하고, 온도조절기는 설정 온도에 따라 히터의 동작을 제어합니다. 습기가 있는 공간에서 사용하는 제어반의 내부 환경을 관리하기 위해 함께 적용했습니다.

## 5. 승인도서 12종 준비 범위

이번 배수펌프 전기공사에 맞춰 아래 12종의 승인도서를 준비했습니다. 함체 외형부터 기기 배치, 전력 계통, 제어 동작, 외부 접속과 자재 사양까지 하나의 제작 기준으로 정리했습니다.

| 문서 | 정리하는 내용 |
| --- | --- |
| 1. 제작승인서 | 제작 대상과 제출 사양, 검토·승인 요청 내용 |
| 2. 외형도 | 함체 치수, 도어와 조작부, 인입·지지 구조 |
| 3. 내부배치도 | 기기·덕트·단자대 배치와 점검 공간 |
| 4. 단선결선도 | 인입 전원, 메인·분기와 부하 계통 |
| 5. 주·제어회로도 | 주전력 회로와 운전·정지·보호 제어 구성 |
| 6. 단자대 결선도 | 외부 케이블 접속 단자와 선번 구분 |
| 7. 펌프 제어 시퀀스도 | 수위·운전모드·보호 조건에 따른 동작 순서 |
| 8. 부하계산서 | 부하 조건과 전원·기기 용량 검토 근거 |
| 9. 주요 자재 사양서 | 적용 기기의 모델·정격·기능 정리 |
| 10. 수위제어 사양서 | 전극봉·검출 방식과 운전 수위 조건 |
| 11. 제품 카탈로그 | 사양 검토를 위한 제조사 자료 |
| 12. 시험검사계획서 | 검사 항목·방법과 확인·기록 계획 |

도면의 기기 명칭과 자재 사양, 배선 선번을 문서별로 맞춰 제작과 결선에 필요한 내용을 정리했습니다. 시험검사계획서에는 검사 항목과 방법, 확인·기록 계획을 담았습니다.
